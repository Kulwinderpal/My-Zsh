## Installation
To Install My Personal Zsh Configuration just run
```
curl -fsSL https://raw.githubusercontent.com/Kulwinderpal/My-Zsh/refs/heads/main/install.sh | bash
```
If you dont have curl installed use wget instead
```
wget -qO- https://raw.githubusercontent.com/Kulwinderpal/My-Zsh/refs/heads/main/install.sh | bash
```
